# Step4 セルフレビュー

- 日付: 2026-11-17
- 対象: タスク追加画面

## 仕様との再照合

- タスク名はtrim後2〜30文字の場合に追加可能。空欄、1文字、31文字以上では追加ボタンを無効化する。
- 31文字以上の入力自体は許可し、入力欄で切り詰めない。
- 日付選択UIから今日以降を選択でき、過去日は選択不可。UseCaseでも日付を検証する。
- 追加成功時のメッセージを表示し、仕様どおり入力値は保持する。
- false応答または例外時に再試行案内と再試行ボタンを表示する。

## 設計確認

- ActivityがActivityスコープのViewModelを保持し、再コンポーズによるViewModel再生成を避けている。
- 追加可否と画面状態、日付表示文字列はViewModel/UseCase側で管理する。
- 表示Composableは状態とイベントコールバックを受け取る形に分離し、Previewを追加した。

## 実施した確認

- `:app:compileDebugKotlin` を実行し、BUILD SUCCESSFULを確認。

## 未実施・残る確認

- Android実機/エミュレーターでの日付ピッカー操作、画面回転時の状態保持、失敗時の再試行操作は実行していない。
- ローカルのAPIモックは有効な入力に対して成功を返すため、失敗UIは例外またはfalse応答に対するコード経路の実装確認までであり、実行時テストは未実施。
- タスク追加成功後の成功メッセージ表示時間は仕様未定義。今回は入力変更でメッセージを解除する現実装を維持した。
